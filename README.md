# FitLog - Workout Library

## Short Description
Hi, this is my gym app project make with Next.js for my assignment. Here u can browse many workout and save them to your daily plan. I make this so people can track their daily lift and see how much calorie they burn. 

## Technologies Used
* Next.js (App router)
* Tailwind CSS for styling
* React Context API
* JSX

## 5 Key Features of the project
1. **API Data Fetching:** It show all workout from API in a nice grid. It look very good in mobile and desktop screen.
2. **Detail Page:** If u click on workout card, it go to detail page where u can see instruction, equipment, and add to plan button.
3. **Daily Plan Calculator:** You can add max 5 workout in Today Plan. It auto calculate total minute and calorie for u.
4. **Local Storage:** Your plan data not delete if you reload or refresh the page because I use browser local storage.
5. **Sort and Manage:** In my plan page u can sort workouts by duration or calorie. Also u can change tab and remove workout if u don't want to do it.
